# Telecom Routing Cost Optimization

This example simulates how telecommunication carriers route data or calls between networks. It demonstrates that by choosing different intermediate carriers, even small per-unit cost differences (the "easy tokens" from the article's metaphor) can lead to significant total cost savings for large volumes of traffic. The script illustrates how "redirecting" traffic through an optimized, less obvious path can impact inter-carrier billing.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python main.py`.
